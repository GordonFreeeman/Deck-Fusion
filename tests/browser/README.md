# Historical browser harnesses

These scripts and screenshots were used for earlier releases. Their selectors and expectations do not describe the v0.3-beta3 guided interface. They are retained as development history, not release verification.

The maintained React/jsdom regression suite is `tests/studio-dom.test.mjs`. Run `npm ci` and `npm test` from the repository root. It uses simulated Steam/Decky services and mocked geometry; it is not a rendering or hardware test.
